# 📸 CodeSnap

**Create beautiful, customizable code screenshots for GitHub, LinkedIn, blogs, and social media.**

CodeSnap is a polished frontend mini-project built with React and Vite. Paste code, customize the visual style, and export the result as a high-resolution PNG.

## ✨ Features

- Live syntax-highlighted preview
- JavaScript, TypeScript, JSX, CSS, HTML, Python and JSON
- Multiple syntax themes
- Multiple gradient backgrounds
- Adjustable padding, radius and font size
- Editable filename
- Dark / light application mode
- Copy screenshot to clipboard
- High-resolution PNG export
- Responsive layout

## 🛠️ Tech Stack

- React
- Vite
- JavaScript
- CSS
- react-syntax-highlighter
- html-to-image
- Lucide React

## 🚀 Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in your terminal.

## 📦 Production build

```bash
npm run build
npm run preview
```

## 🎯 Why I Built This

CodeSnap explores practical frontend concepts including component-based UI, controlled inputs, client-side image generation, syntax highlighting, responsive layouts, and polished interaction design.
